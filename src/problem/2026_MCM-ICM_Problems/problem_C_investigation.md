
# 2026 MCM Problem C 翻译+核心解法+选题评估
## 一、题目翻译（精简核心信息）
### 题目名称：星光相伴的数据（Data With The Stars）
《与星共舞》（DWTS）是英国《舞动奇迹》的美国版国际电视节目，已播出34季。明星与专业舞者搭档，每周表演舞蹈，由专业评委打分，观众通过电话/网络投票支持喜爱的组合（仅可投票留任，不可投票淘汰）。评委得分与观众投票结合，每周淘汰得分最低的组合，最终3支（或更多）组合晋级决赛并排名。

节目曾采用两种投票结合方式：前两季用“排名法”，因争议（如第2季Jerry Rice评委得分极低仍晋级决赛），第3-27季改用“百分比法”；第27季Bobby Bones评委得分持续低迷却夺冠引发争议后，第28季起调整淘汰规则（先按综合得分确定后两名，再由评委投票淘汰其一），并恢复“排名法”。

### 核心任务
1. 基于提供的34季数据（明星信息、比赛结果、每周评委得分），构建数学模型估算每位明星每周的观众投票数（未知机密数据），验证模型是否与每周淘汰结果一致，并量化估算确定性；
2. 对比“排名法”和“百分比法”两种投票结合方式的结果差异，分析哪种更偏向观众投票；针对有争议的明星（如Jerry Rice、Bobby Bones等），分析两种方式是否会改变其结局，以及“评委从后两名中淘汰”规则的影响；
3. 分析专业舞者及明星特征（年龄、行业等）对比赛结果的影响，及其对评委得分和观众投票的影响差异；
4. 设计更“公平”或“更具观赏性”的投票结合系统，为节目制作方提供建议；
5. 提交含1-2页备忘录的报告，总结核心结论与建议。

### 数据说明
数据文件包含34季明星信息（姓名、行业、年龄等）、比赛结果、每周各评委打分（1-10分，含小数/加分/团队舞平均分），存在评委人数变动、部分赛季无淘汰/多淘汰、淘汰后得分为0等情况。

## 二、核心解法（结构化分模块）
本题为**数据驱动的统计建模+方案对比+优化设计**类问题，核心围绕“估算未知观众投票”展开，分5个核心模块落地：

### 模块1：观众投票估算模型（核心基础）
以“每周淘汰结果”为约束，结合评委得分，用**统计回归+约束优化**估算观众投票，两种主流思路：
1. **基于排名约束的估算**（适配排名法赛季）：设每周剩余n位明星，评委得分排名为$R_j$，观众投票排名为$R_f$，综合排名$R=R_j+R_f$（或加权和），淘汰$R$最大者。以“实际淘汰者综合排名最高”为约束，结合明星特征（年龄、行业）和历史数据，用**多元线性回归**拟合观众投票排名与特征的关系，反推未知投票；
2. **基于百分比约束的估算**（适配百分比法赛季）：评委得分百分比$P_j=$ 明星得分/当周所有明星得分总和，观众投票百分比$P_f=$ 明星票数/当周总票数，综合得分$P=P_j+P_f$（或加权和），淘汰$P$最低者。假设观众投票符合**对数正态分布**（票数差异大），以“实际淘汰者$P$最低”为约束，用**最大似然估计**标定分布参数，得到投票估算值；
3. **验证与确定性量化**：用**交叉验证**（如留一季验证）评估模型与淘汰结果的一致性（指标：准确率、混淆矩阵）；用**置信区间/方差分析**量化估算确定性（如热门明星投票估算方差小，边缘明星方差大）。

### 模块2：两种投票方式对比与争议案例分析
1. **跨赛季对比**：对所有赛季同时应用两种结合方式，计算“淘汰结果改变率”“明星最终排名变动幅度”，用**卡方检验/方差分析**判断哪种方式更偏向观众投票（如百分比法中观众投票占比是否更高）；
2. **争议案例深度分析**：对Jerry Rice等争议明星，分别用两种方式重新计算其每周综合得分/排名，判断是否会改变“淘汰/晋级/夺冠”结果；引入“评委从后两名淘汰”规则，模拟后两名的最终淘汰决策，分析规则对争议案例的影响。

### 模块3：影响因素分析模型
构建**双因变量回归模型**（因变量：评委得分、观众投票估算值），自变量：专业舞者知名度（用历史战绩量化）、明星特征（年龄、行业、地区等），用**多元线性回归/随机森林**分析：
- 各因素对评委得分和观众投票的影响系数（如运动员是否更受观众青睐，模特是否更获评委认可）；
- 用**方差解释率（$R^2$）** 量化各因素的总影响权重。

### 模块4：新投票系统设计与优化
基于前序分析，设计**加权融合+动态调整**的新系统，例如：
1. 综合得分$S=α×R_j + β×R_f$（$α+β=1$），用**层次分析法（AHP）** 结合“公平性”“观赏性”目标确定$α$（评委权重）和$β$（观众权重），如$α=0.4$、$β=0.6$；
2. 加入“动态调整机制”：前期（预赛）$β$更高（提升观赏性），后期（决赛）$α$更高（保证专业性）；
3. 验证：用历史数据模拟新系统，对比淘汰结果、争议案例结局、观众投票与评委得分的平衡度，论证其优势。

### 模块5：备忘录与结论提炼
聚焦“投票方式选择”“规则调整建议”，用**量化数据支撑结论**（如“排名法使争议案例发生率降低20%”“新系统公平性提升30%”），给出具体可操作的建议。



# 2026 MCM Problem C 核心思路+目标+KPI体系
## 一、核心建模思路（聚焦“估算未知观众投票”，分阶段落地）
### 阶段1：数据预处理（基础铺垫，3步搞定）
1. **数据清洗**：剔除无效值（如淘汰后0分、无评委得分的N/A），统一时间维度（按“赛季-周”分组），标准化评委得分（如将多舞蹈平均分、加分统一为“单周综合评委得分”）；
2. **特征工程**：提取核心特征——明星特征（年龄、行业、地区）、比赛特征（单周评委得分、累计评委得分、剩余选手人数）、专业舞者特征（历史搭档战绩、赛季胜率）；
3. **标签定义**：以“每周淘汰结果”为核心标签（1=淘汰，0=留任），辅助标签为“最终排名”“是否进入决赛”。

### 阶段2：观众投票估算（核心模块，2种主流方法二选一）
#### 方法A：基于规则约束的回归估算（适配所有赛季，推荐优先选）
1. 核心逻辑：以“实际淘汰者的综合得分（评委+观众）最低”为硬约束，构建“观众投票~特征”的回归模型；
2. 具体步骤：
   - 对每个“赛季-周”，设剩余n名选手，计算单周评委得分排名$R_j$（1=最高）；
   - 假设观众投票排名$R_f$与明星特征（如年龄、行业）、评委得分相关，构建多元线性回归模型：$R_f = a×年龄 + b×行业编码 + c×评委得分 + ε$；
   - 以“实际淘汰者的$R_j+R_f$（或加权和）最大”为约束，用最小二乘法求解回归系数，反推每位选手的$R_f$，再结合“投票数与排名的映射关系”（如排名1的投票数=排名2的1.5倍，基于娱乐节目投票分布规律），估算实际投票数。

#### 方法B：基于分布拟合的最大似然估算（精度更高，适合有统计基础的团队）
1. 核心逻辑：假设观众投票数服从对数正态分布（娱乐节目投票通常呈现“头部集中、尾部分散”特征），以“淘汰结果”为约束，标定分布参数；
2. 具体步骤：
   - 对每个“赛季-周”，设总投票数为$T$（未知，可设为常数或基于赛季热度估算），选手$i$的投票数$V_i \sim LN(μ_i, σ^2)$；
   - 结合两种投票结合方式的规则（排名法/百分比法），建立“$V_i$的分布参数→综合得分→淘汰结果”的映射；
   - 用最大似然估计求解$μ_i$（与明星特征相关）和$σ$，得到$V_i$的估算值及置信区间。

### 阶段3：核心分析任务（按赛题要求逐一突破）
#### 任务1：两种投票结合方式对比
1. 对34季所有“赛季-周”，分别应用“排名法”和“百分比法”计算综合得分，统计：
   - 淘汰结果改变率（同一周用两种方法，淘汰对象不同的比例）；
   - 明星最终排名变动幅度（如冠军是否易主、决赛阵容是否变化）；
   - 用卡方检验判断两种方法对“观众投票的偏向性”（如百分比法中观众投票权重是否更高）。

#### 任务2：争议案例深度分析
1. 选取4个典型争议明星（Jerry Rice、Billy Ray Cyrus、Bristol Palin、Bobby Bones），按以下步骤分析：
   - 提取其参赛所有周的评委得分、估算的观众投票；
   - 分别用两种结合方式重新计算每周综合得分及排名，判断是否会改变“淘汰/晋级/夺冠”结果；
   - 模拟“评委从后两名中淘汰”规则：对争议明星所在周，先确定后两名，再假设评委投票倾向（如更看重专业性→选评委得分更低者淘汰），分析结局是否变化。

#### 任务3：影响因素分析
1. 构建双因变量回归模型（因变量：评委得分、观众投票估算值），自变量：专业舞者特征、明星特征；
2. 用多元线性回归/随机森林求解影响系数，分析：
   - 各因素对评委得分、观众投票的影响方向（如运动员是否更受观众青睐）；
   - 用$R^2$量化各因素的总影响权重（如专业舞者历史战绩对观众投票的解释率）。

#### 任务4：新投票系统设计
1. 设计原则：平衡“专业性（评委）”“观赏性（观众）”“公平性（无争议）”；
2. 具体方案（示例）：
   - 综合得分$S = α×R_j' + β×R_f'$，其中$R_j'$为评委得分标准化排名，$R_f'$为观众投票标准化排名；
   - 动态权重：预赛（前3周）$α=0.3, β=0.7$（侧重观赏性），复赛（4-6周）$α=0.4, β=0.6$，决赛$α=0.5, β=0.5$（侧重平衡）；
   - 淘汰规则：每周按$S$确定后3名，再由评委投票淘汰1名（兼顾专业性与观众意愿）；
3. 验证：用历史数据模拟新系统，对比“争议案例发生率”“淘汰结果合理性”“观众投票与评委得分平衡度”，论证优势。

### 阶段4：报告与备忘录撰写
1. 备忘录（1-2页）：核心包含“投票方式推荐”“新系统建议”“争议案例应对措施”，用量化数据支撑（如“新系统可使争议案例发生率降低30%”）；
2. 报告主体：按“数据预处理→投票估算→核心分析→新系统设计”结构，突出模型合理性、分析深度、结果落地性。
