# Task D — Rule Design & Stress Test Summary

This note summarizes the current Task D work (JS‑SR / "Merit‑Safe"), the stress‑test setup, numeric evaluation (Bias Index), produced artifacts, and recommended next steps.

**Rule (JS‑SR / Merit‑Safe)**
- Design: build a judge‑safeguard set of high‑performing contestants by judges (top quantile), exempt them from elimination, and apply a weighted combined score among the remaining contestants (danger zone).
- Practical effect: preserves professionalism (judges' signal) while allowing fan votes to decide among lower performers.

**Alternate rule evaluated**
- Professional Bottom Two: judges identify bottom two by judge totals, eliminate the lower combined score among them (alpha-weighted). This is a stricter judges-first gate.

Evaluation setup (what we ran)
- Seasons: 1–34 (all seasons present in the dataset)
- Alpha used for p_est in simulations: `0.5` (file naming uses `alpha0p5`)
- Metrics:
  - Bias Index: mean per‑season difference in rank(p) between survivors and eliminated (higher means rule favors keeping higher-p contestants)
  - Jaccard / fidelity and additional per‑contestant summaries (generated by rule-specific evaluators)

Numeric summary (mean Bias Index, alpha=0.5)

| Rule | mean_bias | n_seasons |
|---|---:|---:|
| `rank` | 2.7715770272755567 | 34 |
| `percent` | 2.9351195486612154 | 34 |
| `percentage_bottom_two` (currently labeled `percent_last_two`) | 2.8487738491537513 | 34 |
| `professional_bottom_two` | 0.7840984816938948 | 34 |

Interpretation
- The `professional_bottom_two` rule yields a substantially lower mean Bias Index (~0.78) versus the other rules (~2.7–2.9). That indicates it is less biased toward keeping contestants with higher inferred fan shares (p) compared to the other rules — consistent with its judges‑first gate.
- `percent` and `rank` produce broadly similar Bias Index magnitudes; the `percentage_bottom_two` variant is also similar to them.

Caveats & limitations
- The Bias Index uses the inferred fan vote shares (Task A) and depends on p_est quality and the chosen alpha; results will change under different alpha or alternative p_est approaches.
- Some methods earlier skipped seasons when replay files were missing; in the current run we generated `professional_bottom_two` replays across all 34 seasons to ensure consistent coverage.
- Model instability observed earlier in some elimination‑model fits (GEE) can affect elimination‑derived diagnostics; where GLMM/Bayesian GLMM is appropriate, consider those for inference requiring BLUPs.
- The `percentage_bottom_two` files are currently named using `percent_last_two` — consider a repo rename for consistency.
